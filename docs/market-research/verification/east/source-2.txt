## Cloud Location Finder
For programmatic access to location data across clouds,
consider using [Cloud Location Finder](https://docs.cloud.google.com/location-finder/docs) (CLF), an API which provides up-to-date location
data across Google Cloud, Amazon Web Services (AWS), Azure, and Oracle Cloud
Infrastructure (OCI).
You can easily find locations, get specific location details, find
nearby locations, and filter these based on criteria such as cloud provider, location
type, territory, or carbon footprint.
[Documentation](https://docs.cloud.google.com/location-finder/docs)
